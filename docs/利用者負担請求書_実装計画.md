### 1-3. わかったこと（重要）

- **1割負担はすでに計算済み**。`aggregate.ts` の `copayAmount = Math.min(copayLimit, Math.floor(totalCost / 10))`。
  請求書は「これを転記して、保険外を足す」だけでよい。
- **保険外の自動集計が無い**。おやつ・学習教材は項目マスタに保険外として作れるが、`unit_count`（単位数）しか持てず **円単価を持てない**。→ マイグレーションで `price_yen` を追加するのが素直。
- **日中一時支援** は `billing_service_items.trigger_field='daytime_support'`（category=基本）として単位数で扱われている。
  地域生活支援事業なので国保連ルートとは別建て。利用者負担の計算方法は要ヒアリング。
- `billing_invoices` テーブルは器だけあって未使用。ここに確定した請求書・領収書を保存する。

## 2. 確定仕様（ヒアリング済み・2026-08-26）

### 2-1. 利用者負担の構成

```
利用者負担合計 =
    ① 放デイ給付費の1割   = billing_details.copay_amount
                            （= min(受給者証の負担上限月額, floor(総費用額/10))。集計済みの値をそのまま使う）
  + ② 日中一時支援の1割   = Σ(日ごとの単位数) × 単位数単価 ÷ 10   ★上限額とは別枠（合算しない）
  + ③ 日中一時の送迎      = 片道140円 × 片道回数（往復なら280円）
  + ④ 活動プログラム加算  = activity_programs.extra_charge の合計
                            （日々の記録＝daily_activities の参加チェックから自動集計）
                            パソコン/そろばん=「プログラミング・算数・そろばん」200円、
                            「プリント」200円（★新規追加）、「おやつ」100円
  + ⑤ その他の実費        = billing_actual_costs（手入力）
```

### 2-2. 日中一時支援の単位数表（障害児・18歳未満）

利用時間区分 × 児区分（1〜3）で単位数が決まる。単位数 × 単価(10円) の1割が自己負担。
（例：児区分3の子が1時間利用 → 235単位 → 総額2,350円 → 自己負担235円 / 町へ2,115円）

| 時間区分 | 係数 | 児区分3 | 児区分2 | 児区分1 |
|---|---|---|---|---|
| 2時間未満 | 0.3 | 235 | 185 | 153 |
| 2時間以上4時間未満 | 0.4 | 314 | 246 | 204 |
| 4時間以上6時間未満 | 0.5 | 392 | 308 | 255 |
| 6時間以上8時間未満 | 0.6 | 470 | 369 | 305 |
| 8時間以上 | 0.7 | 549 | 431 | 356 |

- 利用時間は `daily_attendance.daytime_support_start_time / daytime_support_end_time` から算出
- 送迎の有無は `daytime_pickup_arrival_time` / `daytime_dropoff_arrival_time`（`billing_daily_records.daytime_pickup/dropoff` で手動上書き可）
- **児区分は児童の基本情報に持たせる**（`children.daytime_support_category`）

### 2-3. 出力

- ブラウザ印刷用 A4 ページ（個別支援計画書と同じ仕組み：`src/app/print/...` + `PrintOptions`）
- 請求書と領収書を切り替えて印刷。児童ごと・月ごとに1枚。全員分の連続印刷も可能に。

## 4. 実装前に判明していた注意点（重要）

- **`billing_basic_rates` が空**（設定 → 国保連サービスコード・単位数設定が未入力）。
  そのため 202606〜202608 の `billing_details.total_units` は 0 で、**放デイの1割も 0円**になる。
  → 請求書画面に「単位数が未設定です」の警告を出す。単位数を入れれば自動で金額が入る。
- **受給者証（benefit_certificates）が2名分しか登録されていない**。
  負担上限月額が取れない児童は 1割がそのまま自己負担になるため、請求書画面で警告を出す。
- `billing_actual_costs` と `billing_invoices` は現在0件。

### 運用開始前にやること（データ入力）

1. **設定 → 国保連サービスコード・単位数設定** で基本報酬の単位数を登録
   （未登録だと放デイの1割が0円のままになる。`billing_basic_rates` が空だった）
2. **児童詳細 → 受給者証** で負担上限月額を登録（現在2名分のみ）
3. **児童詳細 → 情報編集 → 日中一時支援の児区分** を、日中一時を使う児童に設定
4. 請求明細画面で「出席実績から再集計」を実行
5. 利用者負担額の画面で「全員分を発行」

### 設計上の決めごと

- 放デイの1割は `billing_details.copay_amount` をそのまま使う（国保連に出す金額と必ず一致させるため、再計算しない）
- 日中一時は `daily_attendance.daytime_support_start_time/end_time` の実績時間から時間区分を判定
- 日中一時の送迎は `billing_daily_records` のチェック（手動上書き可）を優先し、なければ到着時刻の有無で判定
- 発行時に `billing_invoices.lines` へ明細をスナップショット。印刷はスナップショットがあればそれを、無ければ現時点の集計を使う
